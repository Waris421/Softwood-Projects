📋 Quick Start Guide — Direct Materials

New here? Follow these steps to get started:

1

Inventory Check

When you receive a new order from a customer, check if you have everything in stock before creating its Style Card.

2

Add Inventory Items

If any required fabric/trim items are missing, add them to the inventory first. Here you will choose the suitable units of measurement and the per unit cost. Go to Inventory → Add Card.

3

Create a Style Card

Once we have the inventory requirement, we calculate the total material consumption to fulfill the order. For this a Style Card in made. Go to StyleCard → Add Card.

4

Create a Work Order

Once all the requirements are finalized, create a work order. Go to Work Order → Add New.

5

Create an Inventory Order

Once the work order has been approved by the client create an inventory order for all the required materials. Go to Inventory Order → Add.

6

Receive the Inventory

Once the goods have been delivered, record the receipt and verify them. Go to Inventory Receipt → Add.

7

Issue the Received Goods

Once all the received goods are verified, issue them for use. Go to Issuance → Issue For Order.

📦 Quick Start Guide — Indirect Materials

Indirect materials are anything not directly involved in apparel production — e.g. Stationary, Medicine, etc. Follow these steps to get started:

1

Create an Inventory Card

Add the material to the inventory with its per unit cost. This is used for cost tracking across all purchases. Go to Inventory → Add Card.

2

Create a Purchase Demand

Raise a purchase demand for the required materials. Go to Purchase Demand → Add.

3

Create a Purchase Order (PO)

Once the required products are finalized, create a Purchase Order for the supplier. Go to Purchase Demand → Make PO.

4

Get the Purchase Order Approved

The PO must be approved before it can be acted upon. Go to Purchase Demand → Approve.

5

Create an Inventory Order

Fill in all the order details including quantities and per unit cost. Make sure the per unit cost from the inventory card is used for accurate cost recording. Go to Inventory Order → Add Order.

6

Record the Delivery

When products are delivered, enter all delivery details including the delivery vehicle information and delivery fee. Go to Inventory Receipt → Add.
